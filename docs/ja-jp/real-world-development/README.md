GitHub Copilot をソフトウェア開発ライフサイクル全体で活用するワークショップです。現実的なシナリオ、完成したアプリケーション、共有されたバックログを使って、変更の計画、コードの作成、動作のテスト、pull request のレビュー、エージェントによる作業管理を学びます。

## シナリオ

あなたは Tailspin Toys の新しい開発者で、ボードゲームの資金調達を支援する架空の会社で働いています。チームのバックログはすでに GitHub Issue として登録されており、あなたが取り組む準備ができています。フィルタリングやページネーション、アクセシビリティやコーディング標準の改善などの作業が含まれています。

## 作業環境を選ぶ

GitHub Copilot は、どこで作業するかに応じてあなたに合わせて使えます。作業したい方法に合う環境を選択してください。各ワークショップは独自のセットアップから始まり、共有された Tailspin Toys のシナリオを使います。

### [GitHub Copilot CLI][cli]

ターミナルでエージェントアシスタントを使います。**Plan** と **Autopilot** モード、指示、スキル、カスタムエージェント、Playwright MCP、Agent Merge、実用的なスラッシュコマンドを使って作業します。

### [GitHub Copilot app][app]

デスクトップアプリで並列エージェントセッションを実行し、セッションモードを切り替え、キャンバスで共同作業し、GitHub の Issue や pull request を管理します。

### [GitHub Copilot cloud agent][cloud]

GitHub Issue を非同期エージェントに割り当て、作業を指示し、その進捗を監視し、開いた pull request をレビューします。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で GitHub Copilot を使います。Copilot Chat の agent mode、MCP server、カスタムエージェントをエディターから使います。
