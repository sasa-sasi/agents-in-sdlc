**[GitHub Copilot cloud agent](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** を使うと、GitHub Copilot がクラウドで非同期に作業できます。GitHub で作業を割り当てると、cloud agent はバックグラウンドでリポジトリを調査し、変更を行い、pull request を作成します。その間、別の作業を進められます。

この演習では、cloud agent が従うカスタム指示を追加し、GitHub Issue を割り当てて作業を実装させます。カスタムエージェントを確認してアプローチを調整し、エージェントダッシュボードでセッションを監視して指示を出します。最後に、作成された pull request をレビューし、結果を反復的に改善します。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランの GitHub アカウント
- [ ] アカウントまたは組織で有効になっている Copilot cloud agent

> [!TIP]
> 有料プランをお持ちでない場合、認証済みの学生は [GitHub Education][callout-student-plan-education] から GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用するエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれているため、すべての環境の演習を完了できます。

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> Cloud agent は **Copilot Student、Pro、Pro+、Business、Enterprise** で利用できます。Copilot Free は対象外です。Copilot Business または Enterprise では、管理者が組織に対して有効にする必要があります。

> [!NOTE]
> この環境では MCP を扱いません。Copilot で MCP server を使用する方法については、[CLI 環境](../cli/)または [VS Code 環境](../vscode/)を参照してください。
